Static asset drop zone for future content.

Use these folders for files you want to keep by path without importing through TypeScript:

- `avatars/`: profile images and character art
- `backgrounds/`: wallpapers and page backgrounds
- `illustrations/`: decorative images for cards and sections
- `gallery/`: screenshots and showcase images
- `bgm/`: background music
- `sfx/`: UI and page sound effects
- `voice/`: spoken clips or character lines
- `docs/`: downloadable attachments for pages

Examples:

- `/assets/backgrounds/home-spring.webp`
- `/assets/avatars/yus-main.png`
- `/assets/bgm/night-loop.mp3`

Files placed here are copied directly into the final GitHub Pages build.
